# Roopesite

A geography-themed portfolio built with React and React-Leaflet.

## Requirements

- Node.js 24.x
- npm 11.x

The Node version is recorded in `.nvmrc`.

## Run locally

```powershell
nvm use 24.21.0
npm install
npm start
```

Open the local URL printed by Vite, usually http://localhost:5173.

## Other commands

```powershell
npm test
npm run build
npm run preview
```
